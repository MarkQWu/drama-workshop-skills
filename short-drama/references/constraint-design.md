# 约束有效性设计原则

本文件定义 short-drama references/ 目录下所有约束条目的写法标准。  
**核心原则：按生成有效性设计约束，不按主观重要程度设计约束。**

---

## 一、为什么"绝不 X"不够

"绝不主动认错"、"不得当众示弱"这类否定式约束有三个工程缺陷：

**缺陷 1：检测边界模糊，产生误报 / 漏报**  
被逼到墙角说了"我错了"，是主动还是被动？LLM 无法稳定判断，/自检 会产生大量误报（有剧情支撑的行为被错误标注）或漏报（换了表达方式的违反被放过）。

**缺陷 2：只说"不做 X"，不说"做什么代替"**  
模型知道不能做什么，但不知道应该做什么。容易生成中性的回避行为，丢失角色质感。

**缺陷 3：把角色成长弧线当 OOC 拦截**  
"绝不"意味着永久禁令。但"打破约束"本身可能是全剧的情感高潮——弧线兑现。纯禁止约束会把成长时刻当 bug 报出来。

---

## 二、完整约束三要素

有效约束必须同时回答三个问题：

| 要素 | 问题 | 为什么必须有 |
|---|---|---|
| **触发情境** | 什么情况下约束被激活？ | 没有情境 = 约束对所有场景一刀切，覆盖到不该管的地方 |
| **替代行为** | 遇到该情境，应该做什么？ | LLM 生成需要正向路径，不只是禁止 |
| **豁免条件** | 什么情况下可以例外？ | B 类约束（角色行为）必须给弧线兑现留空间 |

---

## 三、三类约束分级

约束类型决定豁免条件是否必须：

**A 类（硬规则）**：合规 / 平台 / 格式约束  
- 示例：破折号禁用、对白不加双引号、场景数量限制  
- 特点：客观可测量，允许零容忍，**无需豁免**  
- 判定：有无争议的机器可检测标准

**B 类（角色约束）**：人物性格 / 声音 / 行为约束  
- 示例：声音指纹禁用清单、应激模式、人物互动红线  
- 特点：与弧线和成长紧密相关，**必须含豁免条件**  
- 判定：角色"打破"这条约束是否可能是刻意的戏剧时刻？是 = B 类

**C 类（创作建议）**：血肉层质量导向  
- 示例：建议减少修辞堆叠、建议加更多动作替代台词  
- 特点：主观，**只做建议，不做阻断**

## 四、约束写法模板

### B 类约束标准格式

```
❌ [禁止行为]（[触发误用的典型场景]）
✅ 替代路径：[遇到该情境时，具体做什么]
⚠️ 豁免：[什么情况下允许例外——弧线高潮 / 题材特权 / 特定场景；B 类必须有 ledger 事件支撑]
判定测试：[可 grep 的 pattern 或二选一问句，让 /自检 能稳定触发]
```

### 应激模式（B 类角色约束的推荐格式）

相比"绝不 X"，**应激模式**（应激反应链）是更有效的约束结构：

```markdown
- **应激模式**：
  | 触发情境 | 实际反应 | 替代了什么 | 豁免条件 |
  |---|---|---|---|
  | 被公开指责时 | 反问对方漏洞 → 沉默离场 | 不解释不道歉 | ledger 记录弧线高潮时 |
  | 处于明显弱势时 | 先示敌以弱，私下反制 | 不正面示强 | 终局认输场景（ledger 记录） |
```

这个格式：
- **可正向生成**：LLM 知道该写什么路径，不只是该避什么
- **场景绑定**：不同情境有不同反应，有合理空间
- **弧线容纳**：成长 = 某个触发情境下反应模式的改变，ledger 记录即豁免
- **可检测**：/自检 查"遇到该情境时用了哪条路径"，而非"有没有违反绝对禁令"

## 五、豁免机制与 continuity-ledger 联动

B 类约束的豁免判断走双步验证（/自检 执行）：

```
步骤 1：检测到本集出现约束违反（禁用清单词 / 应激模式偏离）
  ↓
步骤 2：查 continuity-ledger.md #角色动态状态
  ├─ 有对应触发事件记录 → 弧线兑现，标 [骨架层确认]，不阻断
  └─ 无记录 → 未登记的 OOC，标 [骨架层修复]
       建议文案：「此行为偏离角色 [应激模式/禁用清单]，若为刻意弧线节点，
                 请在 continuity-ledger.md 角色动态状态中记录触发事件」
```

口吻风格漂移但未触及禁用清单 / 应激模式：→ `[血肉层建议]`，不阻断。

## 七、维护承诺

**新增约束前必须通过三要素检查**：

- [ ] 已明确触发情境（什么情况激活）
- [ ] 已提供替代行为（应该做什么）
- [ ] B 类约束已写豁免条件（弧线 / 题材 / 特定场景）
- [ ] 已提供可执行判定测试（/自检 能用）

B 类约束缺任一要素 = 不合格，不得并入 references/。
