# 输出模板（辅助命令）

辅助、诊断、导出、工具类命令的标准输出格式（/考据 /导出 /合规 /角色卡 /分镜 /工作流 /帮助 /选题会 /圆桌诊断 /市场 README）。
主创作流程命令模板见 `references/output-templates-core.md`。

## /考据

> 适用于 `/考据 auto`、`/考据 import`、`/考据 view`、`/考据 lock` 四个子命令。

### auto 模式输出

```markdown
# [考据] setting-bible 已建立：auto 模式

## 检索概览

- **题材**：{古装宫廷 / 医疗急诊 / ...}
- **时代/领域**：{南齐 / 现代三甲医院急诊 / ...}
- **盲区警告**：{是 / 否}（命中 short-dynasties.md 时为「是」）
- **WebSearch query 数**：{N}（通道 A：{a} 条，通道 B：{b} 条）
- **WebFetch 抓取**：{成功 N 条 / 失败 M 条}

## bible 字段统计

- **总字段数**：{N}
- **verified**：{N}（权重和 ≥ 6 且含 1 条权重 3）
- **[待人工核源]**：{N}（未达准入门槛）
- **[来源冲突]**：{N}（黑名单源与高权重源矛盾）
- **预计 token**：~{N} / 5000

## 待用户决定项

1. **{字段名}**：[待人工核源]
   - 已检索源：{列表}
   - 选项：A 接受当前（标 [考据待定]） / B 手动补充权威源 / C 加入虚构白名单
2. ...

## 缓存位置

- `setting-bible.md`（项目根）
- `research-cache/`（{N} 个文件）

[完成] setting-bible.md 已建立。状态：auto。输入 /分集目录 继续，或 /考据 view 审查 bible，或 /考据 import {路径} 用用户资料覆盖
```

### import 模式输出

```markdown
# [考据] setting-bible 已建立：import 模式

## 解析概览

- **来源文件**：{路径}
- **格式**：md / txt
- **解析字数**：{N} 字 → ~{N} token

## bible 字段提取

- **元信息**：[完成] / [待补]
- **核心规则系统**：{N} 条
- **术语表**：{N} 条
- **时代/场景常识锚点**：{N} 条
- **已知雷区**：{N} 条
- **虚构白名单**：{N} 条

## 缺失字段

以下 setting-bible-template 必需字段未在用户资料中找到：

1. {字段名}：选项：A 跳过（自检不扣分但提示） / B 切换 hybrid 模式调用 auto 补全 / C 手动补充

[完成] setting-bible.md 已建立。状态：import。输入 /分集目录 继续
```

### view 模式输出

直接打印 `setting-bible.md` 全文，末尾附统计行：

```
---
[bible 状态] {auto/import/hybrid/locked} | 字段总数 {N} | verified {N} / 待核源 {N} / 冲突 {N}
```

### lock 模式输出

```
[考据] setting-bible.md 已锁定（locked）。

锁定后：
- /分集 不允许任何 [虚构] 标注
- 引用 [待人工核源] 字段视为编造，自检 0 分
- 切换 lock → auto/import 需先 /考据 unlock（v1.13 可用）

适用场景：甲方对质量要求极高的项目终审定稿。
```

```markdown

### {角色A姓名}

{姓名}，{年龄}。

### {角色B姓名}
...

## 三、正文

### 第1集：{标题}
{完整剧本内容}

### 第2集：{标题}
```

```
  /分镜 {N}

  操作：按分镜表顺序排列视频片段 → 加字幕/配音/BGM

   python scripts/merge_storyboard.py --episodes 1-10  # 合并分镜
```

## /市场

6 板块固定结构（按顺序输出）：

**1. 榜单速览（TOP 15 表格）**
字段：书名/剧名 | 类别 | 热度/UV_14d | 更新状态 | 是否有改编
排序：`uv_14d` 或 `heat_score` 降序

**2. 题材分布（文字版饼图）**
统计上榜作品按题材标签的分布比例；重点标注：本周首次出现 vs 上周新增的题材

**3. 人设热力 TOP 5**
提取 TOP 15 作品的人设组合，输出高频人设 TOP 5；标注：上升中 / 趋于饱和 / 新冒头

**4. 金手指类型分布**
统计金手指类型；标注：独占稀缺 / 红海 / 新出现

**5. 改编市场信号**
小说→漫剧/短剧改编比例，及近期改编成功率高的题材类型

**6. 操盘建议（3 条以内）**
基于上述数据，指出：值得追的赛道、值得回避的红海、近期黑马信号

## brainstorm

`brainstorm.md` 由 `/开始` 命令逐步写入，贯穿项目构思阶段。

```markdown
# {项目名} · 构思记录

> 本文件由 `/开始` 命令维护，记录项目的构思发散、方向选择、配置决策全过程。

## 元信息

- 项目创建时间：{ISO 8601 时间戳}
- 目标读者：{男性向/女性向/男女通吃}
- 原始输入（seedIdea）：{用户 /开始 Step 3 的原始输入}

## 方向草案

> 发散得到的 4 个故事方向（前 3 个常规方向 + 第 4 个反类型方向），选中 1 个用于 /策划，其余保留供未来参考。

### 方向 1 [选中]

- **Logline**：{一句话梗概}
- **推荐题材**：{题材标签}
- **基调**：{爽文/悬疑/甜宠...}
- **选中理由**：{为什么选这个}

### 方向 2 [淘汰]

- **Logline**：{...}
- **推荐题材**：{...}
- **淘汰理由**：{与目标读者不匹配 / 方向过于相近 / 甲方约束冲突 / ...}

### 方向 3 [淘汰]

- **Logline**：{...}
```
