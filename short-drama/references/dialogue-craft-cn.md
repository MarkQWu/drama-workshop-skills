# 中文对白工艺

> 适用：中文呈现的原创短剧。定位为血肉层 craft 规则，不单独阻断继续生成；只有造成 OOC、剧情信息错乱、不可拍或格式违规时，才按三层控制模型升级。

## 核心原则

好对白不是“漂亮句子”，而是角色在当下不得不说的话。每句关键对白同时检查三件事：

1. **像这个人**：遮住角色名，是否还能听出是谁在说。
2. **有潜台词**：表面说 A，真实意图是 B；不要把愤怒、心软、嫉妒、羞辱直接解释完。
3. **可被替代**：能用动作、道具、沉默、对视或离场表达时，优先删对白。

## /角色开发：声音指纹

`characters.md` 里的 voice 样本集不是金句库，而是“声音指纹”。每个主角色至少写清：

- **句长倾向**：短句 / 中句 / 会绕弯；情绪高峰时是否更短。
- **说话路径**：直问、反问、转移话题、先讲事实再刺人、先示弱再反击。
- **常用动词和称呼**：本角色高频动作词、关系称呼、职业词。
- **躲闪方式**：撒谎时补细节、沉默、转移到工作、用玩笑挡开。
- **情绪失控语言**：愤怒、恐惧、心软、羞耻时语言怎么变形。
- **禁用句式**：这个角色绝不会说的书面腔、解释腔、鸡汤腔、万能狠话。

示例台词服务于上述指纹，不能 5 条同义重复。

## /分集：对白三问

写每场关键对白前，先在脑内过三问，不输出过程：

1. **只有这个角色会这么说吗？** 如果换角色也成立，改成该角色专属说法。
2. **表面意思和真实意图不同吗？** 如果只是解释剧情，改成冲突、试探、遮掩或逼问。
3. **能不能用动作替代？** 如果可以，删对白，改成动作 / 道具 / 沉默。

生成时优先保留有功能的句子：推进剧情、揭示关系、制造冲突、强化人设。寒暄、重复确认、解释观众刚看到的事，默认删除。

## /自检 --fix：删改顺序

`--fix` 修对白时先删后润色：

1. **30% 删除**：标出解释性对白、重复对白、情绪说明对白、凑节奏对白；优先删除或动作化。
2. **大声读检查**：标出拗口长句、书面句、超过角色呼吸节奏的句子。
3. **节奏扫描**：检查是否每个人说话长度差不多、每场戏对白密度差不多；需要有密有疏。
4. **潜台词补回**：把“我很生气 / 我不满意 / 我喜欢你”改成动作、反问、回避或具体物件。

修复建议必须给可替换文本，不能只写“加强潜台词”。

## 新手错误清单

| 错误 | 判定 | 改法 |
|---|---|---|
| 太完整 | 像文章句子，前因后果都说满 | 打断、留半句、交给动作 |
| 太直白 | 角色直接讲情绪和动机 | 用行为展示情绪 |
| 太平均 | 每人句长和对白量接近 | 让强势者压迫、弱势者短答或沉默 |
| 太解释 | 复述观众刚看到的信息 | 删除，或改成新的压力/选择 |
| 太通用 | 换角色说也能成立 | 回到声音指纹重写 |
