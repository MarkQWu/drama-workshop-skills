# 中文对白工艺

> 适用：中文呈现的原创短剧。定位为血肉层 craft 规则。但"对白下限"是硬约束（违反 = 不可拍 = 返工），三问只是优化已写对白的工具，不能用来削减对白到下限以下。

## 核心原则

好对白不是“漂亮句子”，而是角色在当下不得不说的话。每句关键对白同时检查三件事：

1. **像这个人**：遮住角色名，是否还能听出是谁在说。
2. **有潜台词**：表面说 A，真实意图是 B；不要把愤怒、心软、嫉妒、羞辱直接解释完。
3. **可被替代**：当对白只是解释观众已看到的画面、或角色不会自然说出时，才用动作/道具/沉默替代。不是默认偏好删除——能推进剧情、揭示关系、制造冲突、暴露人设的对白必须保留。

## 反 AI 腔与口语化边界

口语化不是粗糙，也不是所有角色都说短平快。它的标准是：这句话像戏内这个人，在这个压力下，对眼前这个对象说出来的。

### 书面连接词降噪

以下词不做绝对禁词，但在冲突现场、情绪高点、短句对峙中默认高风险：

| 高风险写法 | 改写方向 |
|---|---|
| 因此 / 所以 / 鉴于此 / 更何况 / 毫无疑问 | 换成角色自己的判断、命令、反问或直接动作 |
| 我认为 / 我觉得 / 从某种角度来说 / 不可否认 | 删除铺垫，直接说利益、威胁、证据或选择 |
| 这说明 / 这意味着 / 由此可见 | 让对方自己被证据逼到结论，少替观众总结 |

例外：法庭陈述、新闻发布、会议汇报、老师授课等正式场景可以保留部分书面连接，但必须符合职业和场合。

### 激烈情绪下的语言变形

人在愤怒、恐惧、羞耻、狂喜、濒临崩溃时，语言常常会变短、重复、断裂、抢话、改口或只说关键词。不要让角色在身体或情绪失控时仍然说完整论文句。

可用方式：

- 短句压迫：`说。谁让你来的。`
- 重复但有功能：第一次是否认，第二次是确认恐惧，第三次必须升级动作或信息。
- 打断：用另一角色插话或动作打断，不用破折号。
- 改口：角色临时吞回真实意图，暴露关系压力。

### 无意义重复对白

重复不是完全禁止。有效重复必须带来新信息、新压力或新情绪层。以下属于无意义重复：

- A 问一遍，B 不答；A 换同义词再问一遍。
- 同一角色连续解释观众已经看到的画面。
- 用"你说什么 / 我说 / 你再说一遍"拖时间，但没有权力压迫或信息错位。
- 角色轮流确认同一个事实，没有新立场。

修复方式：保留最有压力的一句，删掉同义重复，用动作、证据、第三方打断或新选择替代。

## /角色开发：声音指纹

`characters.md` 里的 voice 样本集不是金句库，而是“声音指纹”。每个主角色至少写清：

- **句长倾向**：短句 / 中句 / 会绕弯；情绪高峰时是否更短。
- **说话路径**：直问、反问、转移话题、先讲事实再刺人、先示弱再反击。
- **常用动词和称呼**：本角色高频动作词、关系称呼、职业词。
- **躲闪方式**：撒谎时补细节、沉默、转移到工作、用玩笑挡开。
- **情绪失控语言**：愤怒、恐惧、心软、羞耻时语言怎么变形。
- **禁用句式**：这个角色绝不会说的书面腔、解释腔、鸡汤腔、万能狠话。

示例台词服务于上述指纹，不能 5 条同义重复。

**voice 样本可执行标准：**

- 每条样本必须能直接放进一个短场景，标清“对谁 / 什么压力 / 真实意图”。
- 台词本体控制在 1-2 句；长 arc 角色最多 1 条可偏宣言，其余必须是现场反应句。
- 样本不是角色小传、作者旁白或高光台词库；不能让角色直接讲完整前史、核心动机或主题总结。
- “情绪失控语言”写语言如何变形，不写动作锚。动作锚如摘眼镜、整理文件、手在抖，放进应激模式或场景动作，不放进 voice。
- 优先写遮掩、反问、改口、转移、短答、错开称呼、突然换话题；少写“我其实……”“我不是那种人”“你以为我……”式自白。

反例：

- 不写：`我十一年前就沉默了，所以我不是你想象中的好人。`
- 改写：`那份卷宗我见过。别问我为什么没签字。`
- 不写：`体面比命重。`
- 改写：`林家的孩子，饭可以乱吃，话不能乱讲。`
- 不写：`我做这一切都是为了顾家和你的前途。`
- 改写：`小迟，把卷宗放回去。你明天还要穿这身制服。`

## 对白合理性下限（情境驱动，非数字硬约束 · 优先级高于"对白三问"）

每个场景的对白量由戏剧动态和合理性决定，不设绝对数字。
但满足以下任一条件的场景必须有对白：

1. ≥2 个角色同框且有戏剧关系动态（冲突 / 信息交换 / 关系变化）
   → 应有对话来回，不能用 OS 独白替代

2. 关键剧情节点（冲突顶点 / 信息差揭露 / 关系转折）
   → 应有对白让戏剧落地，除非剧情明确设计为"无声爆发"且 OS+动作能传达

3. 独角戏但存在外部触发（电话 / 敲门 / 收到消息 / 被人打断）
   → 应有反应性对白

例外（可"无对白"或"极少对白"的场景）：
- 纯动作戏（追逐 / 打斗 / 默剧式情绪表达）
- 蒙太奇 / 转场 / 内心闪回
- 刻意设计的"沉默对峙"高潮节点（必须在场次 purpose 字段显式标注"刻意默剧"理由）

判断准则：每场每个角色的"沉默"，问自己——是剧情设计需要（震惊 / 压抑 / 对峙），还是因为模型没想好该说什么？后者必须补对白。

反 pattern：用 OS 内心独白替代该场景本应有的对话。OS 是补充不是替代。

下限优先于"对白三问"。三问是用来优化已写的对白质量，不是用来减少对白数量。
违反下限 = 不可拍 = 强制返工，等同 H 级硬规则。

## /分集：对白三问

写每场关键对白前，先在脑内过三问，不输出过程：

1. **只有这个角色会这么说吗？** 如果换角色也成立，改成该角色专属说法。
2. **表面意思和真实意图不同吗？** 如果只是解释剧情，改成冲突、试探、遮掩或逼问。
3. **对白和动作哪个更刺？** 只有当动作更能击中观众且不损失信息时才换；动作能补充不能替代角色发声的功能。

生成时先保证对白下限达标（见上方 §对白合理性下限），再筛功能：推进剧情、揭示关系、制造冲突、强化人设的句子优先；寒暄、重复确认、解释观众已看到的事可删，但删后要补一句有功能的对白，不留空缺。

## /自检 --fix：删改顺序

`--fix` 修对白时先删后润色：

1. **筛删 + 替换**：标出解释/重复/凑节奏对白，删的同时用一句有功能的对白补回；总句数不得低于本场对白下限。
2. **大声读检查**：标出拗口长句、书面句、超过角色呼吸节奏的句子。
3. **节奏扫描**：检查是否每个人说话长度差不多、每场戏对白密度差不多；需要有密有疏。
4. **潜台词补回**：把“我很生气 / 我不满意 / 我喜欢你”改成动作、反问、回避或具体物件。

修复建议必须给可替换文本，不能只写“加强潜台词”。

## 新手错误清单

| 错误 | 判定 | 改法 |
|---|---|---|
| 太完整 | 像文章句子，前因后果都说满 | 打断、留半句、交给动作 |
| 太直白 | 角色直接讲情绪和动机 | 用行为展示情绪 |
| 太平均 | 每人句长和对白量接近 | 让强势者压迫、弱势者短答或沉默 |
| 太解释 | 复述观众刚看到的信息 | 删除，或改成新的压力/选择 |
| 太通用 | 换角色说也能成立 | 回到声音指纹重写 |
